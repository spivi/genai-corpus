# genai-corpus

Shared corpus loaders and (from `SPZ-44`) the twelve-line cost-ledger schema for the
*Generative AI Engineering* series on [spivitz.com](https://spivitz.com): every unit
repo in the series pins this package to a commit SHA instead of duplicating the
loading, checksum-verification and cost-accounting code eight times over.

This repo holds a small **fixture corpus** (`fixtures/corpus/`) used by CI and local
tests only — synthetic, non-media stand-ins for the loader's shape. The real ~5 GB
frozen corpus (`v1.0`, checksum manifest) is generated by `SPZ-45` and published as a
Hugging Face dataset; it never enters this git history. See `.gitignore` for the media
extensions this repo refuses to commit, by design rather than by convention.

## Install

Pinned to a commit, from any consuming repo's `pyproject.toml`:

```
genai-corpus @ git+https://github.com/spivi/genai-corpus.git@<commit-sha>
```

Never pin to a branch: a moving dependency would mean a unit's published ledger
numbers were measured against code that no longer exists.

## Development

```bash
python3.12 -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
pytest
jupyter nbconvert --to notebook --execute notebooks/smoke_test.ipynb
```

Requires Python 3.12 (pinned in `pyproject.toml`'s `requires-python`).
